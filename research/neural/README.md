# Neural Research

This area covers the JARVIS Neural Nervous System and future temporal/neuro-inspired experiments.

## Current foundation

The runtime currently provides a deterministic spiking-neural foundation with leaky-integrate-and-fire neurons, weighted directed synapses, delayed spike delivery, bounded plasticity, homeostatic controls, snapshots, and typed event boundaries.

It is **not** a full biological fruit-fly connectome. Connectome-inspired work belongs here only when topology, data source, scaling assumptions, and validation are documented.

## Planned studies

- Temporal pattern classification
- SNN versus simple non-spiking baselines
- Connectome-inspired sparse topology
- Plasticity stability under long runs
- Latency and memory scaling
- Hardware acceleration experiments

## Rule

A biological analogy is a design inspiration, not evidence that the implementation reproduces a biological brain.

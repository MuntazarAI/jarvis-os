# Fly Brain (4.1)

## Honest statement

There is **no measured biological connectome** in this repository. The
12-population, 166,000-neuron schema in `jarvis/neural/topology.py` is
**schematic and synthetic**: population names are inspired by Drosophila
anatomy (lamina, medulla, lobula, antennal lobe, mushroom body, central
complex, …), but neuron counts, projection patterns, weights, and delays
are generated by a seeded random process — clearly tagged
`origin="synthetic"` at every level (schema, edges, snapshots, docs).

Nothing in code, tests, or docs claims these numbers are measured biology.

## What was built

- `ConnectomeSchema`: populations + projections with fan-out/weight/delay
  distributions, `validate()`, JSON `to_dict`/`load_schema` round-trip.
- `SyntheticGenerator(seed)`: deterministic, deduplicated, sorted edges.
- `validate_edges()`: bounds/NaN/self-loop diagnostics for any edge list.
- `FLY_166K_SCHEMA`: 12 populations totaling exactly 166,000 neurons, 16
  projections (~1.67M edges generated in ~3.4 s on this laptop).
- Loader interface: `ConnectomeSchema.load_schema(path)` accepts any JSON
  file in the same format — the day real connectome data (e.g. FlyWire
  exports converted to population/projection JSON) is available, it loads
  through this path with `origin` set to its true source.

## What is missing (real connectome data)

1. A real dataset: per-neuron types/positions and per-synapse
   pre/post/weight/delay lists, licensed for local use.
2. A converter from that dataset's format into the schema JSON.
3. Validation of simulated dynamics against biological recordings.

Until then, the synthetic schema exercises the full 166k pipeline
honestly: generation → compile → stepping → snapshot → replay.

# JARVIS-OS Roadmap

This roadmap is a development map, not a promise of delivery dates.

## Foundation

- [x] Local-first architecture
- [x] Policy/security boundary
- [x] Device fabric
- [x] Android node foundation
- [x] Neural Nervous System foundation
- [x] Plugin SDK foundation
- [x] Benchmark/release automation

## Near-term engineering

- [x] Complete and validate Android 3.10 transport E2E
- [x] Add persistent device grants, approvals, durable command outbox, drainer, CLI and audit (4.2)
- [ ] Complete async operator UX for persistent grants and approval notifications
- [ ] Build and validate the 4.2 end-to-end cognitive loop
- [ ] Add Raspberry Pi device node
- [ ] Expand typed transport coverage
- [ ] Improve deterministic benchmark reporting
- [ ] Reduce and classify pre-existing test failures
- [ ] Expand API documentation

## Research

- [ ] Connectome-inspired topology experiments
- [ ] Temporal SNN benchmarks against simple baselines
- [ ] Memory retrieval experiments
- [ ] Agent planning benchmarks
- [ ] Perception latency/accuracy studies

## Platform

- [ ] Nightly health reports
- [ ] Published container images
- [ ] Hardware compatibility reports
- [ ] Developer portal expansion
- [ ] Reproducible release artifacts
- [ ] GitHub Project/roadmap board when project-management API access is available

## Principle

Build the smallest measurable step, verify it, then expand.

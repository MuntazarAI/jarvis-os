# Hardware Report — primary laptop (2026-10-03)

First reproducible report for the hardware compatibility lab
(see `docs/HARDWARE.md`). Every number below was measured on this
machine today; untested targets are marked, not assumed.

## Host

- Model: Ubuntu laptop, Intel Alder Lake-UP3 (UHD Graphics, iGPU only)
- CPU: 8 threads (`nproc`), no CUDA device
- RAM: 6GiB total (~1–2GiB typically available), 15GiB swap
- Disk: 258GiB NVMe, ~12GiB free at report time (96%)
- OS: Ubuntu 26.04.1 LTS
- Python: system 3.14.4; project `.venv` 3.12.13; chatterbox venv 3.12.13

## Peripherals

- Audio playback: HDA Analog (`sofhdadsp`), `aplay` present — command
  invocation TESTED (exit 0), audible output NOT TESTED by agent
- Microphone: `arecord` present — backend detection TESTED, content
  recording NOT TESTED
- Camera: `/dev/video*` present (doctor), capture NOT TESTED here

## Workloads measured

| Full test suite | 902 passed, 3 skipped |

## Known limitations (this host)

- RAM is the binding constraint; one Chatterbox synthesis peaks at
  ~4.1GiB RSS. No sustained/parallel voice workloads validated.
- faster-whisper installed but runtime-blocked by PyAV
  `metadata_errors` incompatibility (STT and TTS tracked separately).
- Disk: voice runtime (1.6GiB) + model weights (~9.9GiB HF cache
  incl. faster-whisper) dominate usage.
